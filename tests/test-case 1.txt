Тест-кейс №1: Регистрация с минимально допустимыми данными
Атрибут	Значение
ID	TC_REG_POS_01
Название	Успешная регистрация с заполнением только обязательных полей
Предусловия	Открыта страница регистрации, пользователь не авторизован
Шаги	1. Ввести в поле «Имя»: Анна
2. Ввести в поле «Фамилия»: Иванова
3. Ввести в поле «Email»: anna.ivanova@example.com
4. Ввести в поле «Пароль»: Qwerty123!
5. Ввести в поле «Подтверждение пароля»: Qwerty123!
6. Отметить чекбокс «Согласен с условиями»
7. Нажать кнопку «Зарегистрироваться»
Ожидаемый результат	Сообщение об успешной регистрации, пользователь перенаправляется на страницу входа или в личный кабинет. В базе данных появляется новая запись с указанными данными.
