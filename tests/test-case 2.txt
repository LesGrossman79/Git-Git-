Тест-кейс №2: Регистрация с максимальной длиной полей
Атрибут	Значение
ID	TC_REG_POS_02
Название	Успешная регистрация с данными максимально допустимой длины
Предусловия	Открыта страница регистрации
Шаги	1. Ввести «Имя» из 50 символов (например, строка из латиницы)
2. Ввести «Фамилию» из 50 символов
3. Ввести «Email» длиной 254 символа (максимум для RFC) – допустимый формат
4. Ввести «Пароль» из 128 символов (смесь букв, цифр, спецсимволов)
5. Подтвердить пароль
6. Принять условия
7. Нажать «Зарегистрироваться»
Ожидаемый результат	Регистрация успешна, данные сохраняются без обрезания. Ошибок валидации нет.
